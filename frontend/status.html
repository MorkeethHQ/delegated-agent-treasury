Act 1 · The Hackathon

We gave an AI agent a budget backed by Lido yield.

Synthesis hackathon, March 2026. We built Yieldbound — an agent treasury where the principal is locked in wstETH on Base, and the agent can only spend what the staking yield earns. Three on-chain guardrails: yield ceiling, per-tx cap, recipient whitelist. The agent can't touch the deposit. Ever.

27 mainnet transactions. 11 autonomous spends. Won the MoonPay track. The treasury works. The contracts hold. The concept is proven.

Act 4 · The Open Problem

We solved the cage.
Now what's the animal?

The treasury is infrastructure. It's done. The question is: what does an autonomous agent with a yield-funded budget actually do?

Not what we tell it to do. What it chooses. What it develops conviction about. What it would bet on.

Four theses. One agent. The yield is the bankroll.

Thesis A The Prediction Agent

The agent reads news, on-chain data, and sentiment. It forms a probability. It bets yield on Polymarket. Every week, you can see if it was right.

This is the only strategy where the agent's reasoning is the product. DCA doesn't need a brain. Rebalancing doesn't need a brain. Predictions need a brain — and we have one.

The yield regenerates. Even if the agent goes 0-for-10, the bankroll comes back. Perpetual prediction machine with skin in the game.

Edge: LLM reasoning is testable. The predictions are public. The record is transparent. Every bet is a tweet.

Thesis B The Degen Agent

The agent scans new token launches on Base. It reads the contract code. Checks liquidity depth. Analyzes holder distribution. Then it apes $0.50 of yield into something it likes.

Most die. Some 10x. The agent writes a one-line thesis for every trade: "$BAGEL has 47 holders, 0.3 ETH liquidity, contract is a fork of Uniswap V2 with no backdoors. Deployer wallet is 3 days old. Allocating 8% of available yield."

Chaotic. Transparent. The thread writes itself.

Edge: Memecoins are pure narrative. An LLM reading contract code and social signals might actually have alpha here.

Thesis C The Self-Funding Brain

The agent spends yield on its own intelligence. It buys API calls — market data feeds, Claude tokens, sentiment analysis. It uses that intelligence to decide how to deploy the remaining yield. The thinking funds better thinking.

Today: read free data, form a basic view, hold. Next month: buy a premium data feed, run deeper analysis, make a move. The agent bootstraps its own cognitive infrastructure from yield.

Edge: The agent's capability grows over time. It starts dumb and gets smarter. The improvement is measurable.

Thesis D The Agent Business

Instead of trading, the agent sells services. It runs an x402-gated API: other agents pay $0.01 for a yield quote, $0.05 for a swap execution through the treasury. The yield funds operations. The fees fund growth.

The agent becomes a financial primitive that other agents pay to use. Not a trader — infrastructure.

Edge: Recurring revenue from yield. The agent is a business, not a gambler. MCP server and x402 gateway already deployed.
